我现在有一个极其复杂的项目要做：这个项目是一个多agent harness，客户端界面是一个类似discord的聊天窗用来host用户和agent的聊天，往下一层是不同agent相互的交流层，一个agent可以和其余agents建立一个或者多个会话，再往下一层是项目记忆层。这个层有两个部分，一个是知识图，每一个用户新增的文档，agent查处的重要文献都会成为这个知识图中的节点；另一个是agent自己的记忆，包括role，rules，以及根据庞加莱球面所形成的分级记忆。我对这个项目的期望是高度自定义化，用户可以根据其需求定制agent集群，达成市场调研，投资分析，autoresearch等多个功能。
