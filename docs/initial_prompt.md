我现在有一个极其复杂的项目要做：这个项目是一个多agent harness，客户端界面是一个类似discord的聊天窗用来host用户和agent的聊天，往下一层是不同agent相互的交流层，一个agent可以和其余agents建立一个或者多个会话，再往下一层是项目记忆层。这个层有两个彼此隔离的部分。一个是这个 project 的知识图：节点是 DOCUMENT、PAPER、CLAIM、CONCEPT，边是引用、推导、依赖、支持、反驳。另一个是每个 agent 自己的记忆，包括 role、rules、principle、episode，只给这个 agent 用，不和其他 agent 共享，也不写进知识图。我对这个项目的期望是高度自定义化，用户可以根据其需求定制agent集群，达成市场调研，投资分析，autoresearch等多个功能。
